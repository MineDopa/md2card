Md2Card：把 Markdown 笔记变成小红书图片

Md2Card 适合日常 Markdown 笔记：学习总结、读书摘录、课程笔记、技术文章或知识整理都可以直接导入。

纯前端、本地处理、预览即导出。这是一篇首次打开工作台就能完整阅读的产品演示：不需要上传文件，也不需要先授予图片目录权限。
