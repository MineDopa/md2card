**架构坑（下次改主题必看）**
1. 存在**两套并行主题系统**：`src/styles/app.css` 里有一套旧的 `--cover-*` + 硬编码色的 `.theme-editorial/notebook/research` 巨型规则；新的权威系统是 `cards/base.css`（`--theme-*` 角色变量 + 几何） + `cards/themes/*.css`。
   加载顺序 app.css → base.css → themes/*.css → code-appearance.css → theme-picker.css → workbench.css，**同特异性时后者赢**。新建主题只要不叫已有名字，就不会被 app.css 的旧规则污染。
2. 代码外观是**独立于主题**的第二维度，改的只是 `.code-card`，且 MeasureStage 同带类名 → 窗口栏高度会进入真实分页测量。
3. `--theme-code-surface` 若设深色，必须同步覆盖 `.code-card pre { color }`，否则 base.css 的 `color: var(--theme-on-surface)` 会造成深底深字。
4. 分隔线母题用了 `hr::before` 的 content（`— ✧ ◆ ✧ —`），刻意避开 emoji（⌛ 会掉色成彩色表情）。
